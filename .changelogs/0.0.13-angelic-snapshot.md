* Rebranded An Extra Touch to Angelic Industries, including package names, links, author metadata, and Maven publication.
* Replaced FentLib with **AngelLib 1.0.0 or newer**. UniMixins and GTNHLib are also required.
* Moved the experimental sound editor into the separate Sound Manager project. AET does not require Sound Manager.
* Updated the build and publishing setup. Past Footsteps remains optional.

**Compatibility:** Java API packages changed from `org.fentanylsolutions.anextratouch` to
`industries.angelic.anextratouch`. Add-ons using AET's API need an update. The mod ID and existing config names
remain `anextratouch`.

This is a preview of 0.0.13; broader gameplay and cross-mod acceptance is still in progress.
